# **App Name**: HealthLink Pharmacy

## Core Features:

- Product Catalog & Search: Browse featured categories (Chronic, Wellness, Baby Care), use a prominent search bar, and view a 'Top Deals' slider on the homepage.
- Medicine Substitutes: When searching for a medicine, display the main product and a 'Save More' section listing generic substitutes with the same salt composition but lower prices.
- Product Details Page: Display comprehensive product information including price, manufacturer, salt composition, and a clear 'Add to Cart' button.
- Prescription Upload & AI Analysis: Users can upload prescription images via camera/gallery, with a preview. An AI tool will analyze images for legibility and attempt to pre-fill medication details, assisting faster pharmacist review.
- Secure User Authentication: Enable user registration and login using Google Sign-in and email/password authentication (via Firebase Authentication).
- OTP-based Customer Login: Allows users to securely log in using a One-Time Password sent to their registered mobile number or email.
- Shopping Cart & Checkout: Manage items and quantities in a persistent shopping cart, culminating in a secure checkout flow that captures delivery addresses.
- Supervisor Admin Panel: A separate, secure panel requiring supervisor username and password login to manage orders and view uploaded prescriptions.

## Style Guidelines:

- Primary color: A professional and trustworthy Blue (#0056B3), serving as the dominant color for interactive elements, branding, and key information.
- Accent color: A vibrant and warm Orange (#FF8C00) used sparingly for calls to action, highlights, and positive feedback.
- Background colors: Clean White (#FFFFFF) for primary content panels and cards for optimal readability, complemented by a very light off-white or subtle grey (#F8F8F8) for general backgrounds to provide depth.
- All text will use 'Inter', a grotesque-style sans-serif font known for its clarity and objective neutrality across various screen sizes, ensuring high legibility for product descriptions and general UI elements.
- Employ a consistent set of clean, modern, and easily recognizable line icons with rounded edges, aligning with a Material Design-inspired aesthetic for intuitive navigation.
- Utilize a spacious and card-based layout inspired by 'PlatinumRx' to clearly separate content blocks, emphasize product information, and maintain a high-end, organized visual flow.
- Incorporate subtle, functional animations for user feedback, such as item additions to the cart, page transitions, and modal displays, enhancing the user experience without distraction.
